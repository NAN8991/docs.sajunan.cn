# 区块链入门

区块链方向主要围绕智能合约与链上应用的安全问题，核心是理解合约的存储、调用与资产流转方式。

## 学习建议

1. 先理解账户、交易、Gas 与合约存储的基本概念。
2. 熟练使用 Foundry 在本地复现和调试合约调用。
3. 从简单的合约审计题开始，逐步分析真实漏洞案例。
