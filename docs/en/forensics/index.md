# Forensics Basics

Forensics challenges ask you to reconstruct what happened from disk images, memory dumps, logs and files.

## Study tips

1. Learn the basics of file systems and operating systems.
2. Get familiar with Autopsy, Volatility, Wireshark and foremost.
3. Always work on a copy of the evidence and keep the original untouched.
