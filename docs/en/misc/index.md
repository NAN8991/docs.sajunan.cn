# Misc Basics

Misc is the most flexible CTF category. It covers encoding, steganography, traffic analysis, interactive games and more.

::: info In progress
This category is being written. Planned topics:

- Common encodings and nested encoding chains
- Image, audio and file-format steganography
- Archive passwords and fake encryption
- Packet capture analysis
- QR codes, barcodes and image processing
- Automation scripts for repetitive tasks
- Forensics-style combined challenges
:::

## Study tips

1. Learn CyberChef, 010 Editor, binwalk and zsteg.
2. Inspect file headers and structure before guessing.
3. Be patient: misc challenges often require combining several ideas.
