# Reverse Engineering Basics

Reverse engineering challenges ask you to recover the logic of a compiled program and find the flag.

::: info In progress
This category is being written. Planned topics:

- Executable formats (PE / ELF) and the compilation pipeline
- Static analysis with IDA and Ghidra
- Dynamic debugging with x64dbg, gdb and Frida
- Recognizing common encryption and validation routines
- Packers, obfuscation and anti-debugging
- Python bytecode, Android, .NET and WebAssembly
:::

## Study tips

1. Understand how C code maps to assembly instructions.
2. Combine dynamic debugging with static analysis.
3. Practice algorithm recovery and collect signatures of common crypto routines.
