# 取证入门

取证方向从磁盘镜像、内存转储、日志和文件中提取证据，还原攻击或事件的发生过程。

- 内存取证（Volatility）

- 浏览器、邮件与聊天记录取证
- 文件恢复与数据雕刻

- 时间线分析与证据关联

## 学习建议

1. 了解常见文件系统与操作系统的基本结构。
2. 熟悉 Autopsy、Volatility、Wireshark、foremost 等工具。
3. 养成先做镜像备份、再进行分析的习惯，保证证据不被破坏。
