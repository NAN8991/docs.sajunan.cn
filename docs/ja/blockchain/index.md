# ブロックチェーン入門

ブロックチェーン分野は主にスマートコントラクトとオンチェーンアプリケーションのセキュリティ問題を扱い、核心はコントラクトのストレージ、呼び出し、資産の流れを理解することにあります。

::: info コンテンツ制作中
このカテゴリの記事は現在整理中で、今後順次追加していきます。まずは以下のテーマから準備を始めるとよいでしょう：

- ブロックチェーンの基礎と EVM の実行モデル
- Solidity 言語とコントラクトのデプロイ
- リエントランシー攻撃（Reentrancy）
- 整数オーバーフロー、アクセス制御、権限バイパス
- 乱数とタイムスタンプの操作
- プロキシコントラクトとアップグレードの脆弱性
- フラッシュローン、オラクル、価格操作
- Foundry、Slither などの監査・デバッグツール
:::

## 学習のアドバイス

1. まずアカウント、トランザクション、Gas、コントラクトストレージの基本概念を理解しましょう。
2. Foundry を使いこなし、ローカルでコントラクト呼び出しを再現・デバッグできるようにしましょう。
3. 簡単なコントラクト監査問題から始め、徐々に実際の脆弱性事例を分析していきましょう。
