# フォレンジック入門

フォレンジック分野では、ディスクイメージ、メモリダンプ、ログ、ファイルから証拠を抽出し、攻撃や事件がどのように発生したかを再現します。

::: info コンテンツ制作中
このカテゴリの記事は現在整理中で、今後順次追加していきます。まずは以下のテーマから準備を始めるとよいでしょう：

- ディスクイメージとファイルシステムの解析
- メモリフォレンジック（Volatility）
- Windows イベントログとレジストリ
- ブラウザ、メール、チャット履歴のフォレンジック
- ファイル復元とデータカービング
- ネットワークトラフィックと PCAP 解析
- タイムライン分析と証拠の関連付け
:::

## 学習のアドバイス

1. 一般的なファイルシステムと OS の基本構造を理解しましょう。
2. Autopsy、Volatility、Wireshark、foremost などのツールに慣れましょう。
3. まずイメージのバックアップを取得してから解析する習慣を身につけ、証拠が破壊されないようにしましょう。
