# Misc 入門

Misc は CTF の中で最も自由度の高い分野で、エンコード変換、ステガノグラフィ、トラフィック解析、ゲームとの対話など、さまざまな問題形式をカバーします。

::: info コンテンツ制作中
このカテゴリの記事は現在整理中で、今後順次追加していきます。まずは以下のテーマから準備を始めるとよいでしょう：

- 定番のエンコードと多重エンコードの入れ子
- 画像、音声、ファイル形式のステガノグラフィ
- 圧縮ファイルのパスワードと偽暗号化
- トラフィック解析（PCAP）
- QR コード、バーコード、画像処理
- スクリプト作成と自動解答
- フォレンジック系と雑多な総合問題
:::

## 学習のアドバイス

1. CyberChef、010 Editor、binwalk、zsteg などのツールを使いこなしましょう。
2. 見慣れないファイルに出会ったら、まずファイルヘッダと構造を確認し、そのうえで隠蔽方法として考えられるものを判断しましょう。
3. 根気を保ちましょう。Misc はさまざまな発想を試し組み合わせ続けることがしばしば必要です。
