# Reverse 入門

Reverse 分野では、コンパイル済みのプログラムからロジックを復元し、検証アルゴリズムや隠された Flag を見つけ出すことが求められます。

::: info コンテンツ制作中
このカテゴリの記事は現在整理中で、今後順次追加していきます。まずは以下のテーマから準備を始めるとよいでしょう：

- 実行ファイル形式（PE / ELF）とコンパイルの流れ
- 静的解析：IDA、Ghidra、逆アセンブリの読解
- 動的デバッグ：x64dbg、gdb、Frida
- 定番の暗号化・検証アルゴリズムの識別
- パッキング、難読化、アンチデバッグへの対抗
- Python のリバースとバイトコード解析
- Android、.NET、WASM などの特殊なプラットフォーム
:::

## 学習のアドバイス

1. C 言語のコードとアセンブリ命令の対応関係を理解しましょう。
2. まず動的デバッグ、次に静的解析という順で進み、実行時のレジスタやメモリの変化と合わせてプログラムの挙動を理解しましょう。
3. アルゴリズム復元系の問題を多く解き、定番の暗号アルゴリズムの特徴を蓄積しましょう。
