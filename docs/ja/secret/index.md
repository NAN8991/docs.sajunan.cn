# 隠しページを見つけました

おめでとうございます。ここはナビゲーションに載っていないイースターエッグページです。

```text
flag{54GM5rOo5aGU6I+y6LCi6LCi5Za1}
```

中括弧の中は Base64 で、デコードすると：**灌注塔菲谢谢喵**。

> ここには問題はなく、一言の挨拶だけがあります。[暗号入門](/ja/crypto/) へ進んで学習を続けましょう。
