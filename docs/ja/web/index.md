# Web 入門

Web 分野では、Web サイトや Web アプリケーションにおけるセキュリティ問題を扱います。核心は、データがブラウザからサーバーへと流れる一連の過程を理解することにあります。

::: info コンテンツ制作中
このカテゴリの記事は現在整理中で、今後順次追加していきます。まずは以下のテーマから準備を始めるとよいでしょう：

- HTTP プロトコルとブラウザの同一オリジンポリシー
- SQL インジェクション、XSS、CSRF、SSRF
- ファイルアップロード、ファイルインクルード、ディレクトリトラバーサル
- SSTI、デシリアライゼーション、プロトタイプ汚染
- JWT、OAuth、認証バイパス
- 一般的なミドルウェアとフレームワークの脆弱性
:::

## 学習のアドバイス

1. HTTP リクエストとレスポンスに慣れ、ブラウザの開発者ツールでパケットをキャプチャして分析できるようにしましょう。
2. スクリプト言語を一つ習得し（Python を推奨）、簡単な自動悪用スクリプトを書けるようにしましょう。
3. ローカルに演習環境を構築し、各種類の脆弱性を自分の手で再現して、Payload を丸暗記するのではなく成因を理解しましょう。
