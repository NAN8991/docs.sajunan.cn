# Misc 入门

Misc 是 CTF 中最灵活的方向，涵盖编码转换、隐写、流量分析、游戏交互等各种题型。

::: info 内容建设中
本分类的文章正在整理中，后续会陆续补充。可以先从以下主题开始准备：

- 常见编码与多层编码嵌套
- 图片、音频、文件格式隐写
- 压缩包密码与伪加密
- 流量分析（PCAP）
- 二维码、条形码与图像处理
- 脚本编写与自动化解题
- 取证类与杂项综合题
:::

## 学习建议

1. 熟练使用 CyberChef、010 Editor、binwalk、zsteg 等工具。
2. 遇到陌生文件先看文件头与结构，再判断可能的隐藏方式。
3. 保持耐心，Misc 往往需要不断尝试与组合多种思路。
