# Reverse 入门

Reverse 方向要求从编译后的程序中还原逻辑，找到校验算法或隐藏的 Flag。

::: info 内容建设中
本分类的文章正在整理中，后续会陆续补充。可以先从以下主题开始准备：

- 可执行文件格式（PE / ELF）与编译流程
- 静态分析：IDA、Ghidra、反汇编阅读
- 动态调试：x64dbg、gdb、Frida
- 常见加密与校验算法识别
- 加壳、混淆与反调试对抗
- Python 逆向与字节码分析
- Android、.NET、WASM 等特殊平台
:::

## 学习建议

1. 理解 C 语言代码与汇编指令之间的对应关系。
2. 先动调、后静态，结合运行时的寄存器与内存变化理解程序行为。
3. 多做算法还原类题目，积累常见加密算法的特征。
