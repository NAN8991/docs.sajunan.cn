# 你找到了隐藏页面

恭喜，这里是一个不在导航里的彩蛋页面。

```text
flag{54GM5rOo5aGU6I+y6LCi6LCi5Za1}
```

大括号里是一段 Base64，解码后是：**灌注塔菲谢谢喵**。
