# Web 入门

Web 方向关注网站与 Web 应用中的安全问题，核心是理解数据从浏览器到服务端的完整流转过程。

::: info 内容建设中
本分类的文章正在整理中，后续会陆续补充。可以先从以下主题开始准备：

- HTTP 协议与浏览器同源策略
- SQL 注入、XSS、CSRF、SSRF
- 文件上传、文件包含与目录穿越
- SSTI、反序列化、原型链污染
- JWT、OAuth 与认证绕过
- 常见中间件与框架漏洞
:::

## 学习建议

1. 熟悉 HTTP 请求与响应，会用浏览器开发者工具抓包分析。
2. 掌握一门脚本语言（推荐 Python），能编写简单的自动化利用脚本。
3. 搭建本地靶场，亲手复现每一类漏洞，理解成因而不是死记 Payload。
